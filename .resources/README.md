# Offline Python packages

Use this folder to store Python packages downloaded on a machine with internet access.

Default package cache path used by the helper scripts:

```text
.resources/packages
```

Download packages on an online machine:

```bash
python3 scripts/download_offline_packages.py
```

Install packages on an offline machine:

```bash
python3 scripts/install_offline_packages.py
```

If your environment uses `python` instead of `python3`, replace the executable accordingly.
